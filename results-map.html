Results map: every configuration

Each tile is one configuration of the results grid in the video (dataset, number of training points, number of clusters k): 234 configurations over 16 datasets, from 100k to 100M points. The curves are test MSE on each benchmark’s official query set, averaged over seeds. The blue number is how many times fewer epochs e-means needs to reach the loss k-means has after 25 epochs: median 12.6×.
