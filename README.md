# e-means

The website of e-means, a modern k-means algorithm developed at Meta FAIR:
the blog post (`index.html`), the in-browser playground (`playground.html`)
and a CPU-only Colab notebook (`EMEANS_COLAB_DEMO.ipynb`).

Served by GitHub Pages at https://e-means.github.io. The pages are static HTML,
built from the authors' working copies; `.nojekyll` makes GitHub serve them as is.
